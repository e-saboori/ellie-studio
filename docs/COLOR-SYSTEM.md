# Ellie Studio Color System

The palette keeps Ellie Studio warm and personal while distinguishing it from beige and brown portfolio designs. Forest green carries the brand and interactive hierarchy; coral is reserved for small expressive details.

## Tokens

| Token | Value | Role |
| --- | --- | --- |
| `--color-bg` | `#F7F4EE` | Main page background |
| `--color-surface` | `#FFFFFF` | Forms and clean elevated surfaces |
| `--color-surface-soft` | `#E9EEE7` | Sage section blocks and decorative shapes |
| `--color-text` | `#1F211E` | Main text |
| `--color-muted` | `#6F746B` | Supporting text |
| `--color-primary` | `#3F5F4A` | Buttons, icons, active navigation, and brand accents |
| `--color-primary-dark` | `#2F4637` | Hover states and stronger green contrast |
| `--color-accent` | `#D96F4B` | Small decorative marks and selected emphasis |
| `--color-accent-soft` | `#F3C9B8` | Subtle accent details |
| `--color-line` | `#D8D3C8` | Borders and dividers |
| `--color-card` | `#FBFAF6` | Content and pricing cards |

## Usage Rules

- Use green for actions, navigation state, service icons, and meaningful emphasis.
- Use coral sparingly for headline emphasis, prices, hearts, stars, and underline marks.
- Use white or card surfaces for readable content areas and forms.
- Use sage for soft background shapes and section separation.
- Avoid large coral backgrounds and avoid reintroducing brown or strong beige tones.
